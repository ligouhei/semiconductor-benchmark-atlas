哪些任务值得继续做，哪些已有成熟原生能力？

成熟软件提供某项求解能力，不能直接推出含该工具的工程任务已解决。应分清：求解器本身、工具控制/编排、工程闭环、独立物理验收。

以下为基于已核资料的研究选择判断，不是本轮跑模型所得成绩或覆盖行业全部任务的证明。

数字前端

小型RTL单模块生成

成熟工具已经承担什么
编译器、lint、仿真器和形式工具已经承担语法/电路执行/等价检查；成熟IP可以直接复用。
Agent仍需完成什么
从新规格正确构造实现、处理边界、读懂失败并修复；不是再让语言模型发明Verilog parser。
研究用途判断
作为基础回归或低成本能力筛查；单独作为最前沿agent主榜证据较弱。
必须保留的验收
隐藏独立TB/形式规格，失败、超时、不可判定全计分母；固定预算和gold隔离。
数据可得性
多套公开任务；HORIZON完整训练轨迹未定位。
饱和/版本/可比性边界
HORIZON在有限既有套件的多轮完成率很高，且含一题harness修正；这是局部饱和证据，不证明任意RTL工程已解决。

对应目录：NVIDIA HORIZON / repository-evolution method evaluation · VerilogEval v2

数字前端

多文件RTL工程与跨前后端任务

成熟工具已经承担什么
工具可仿真、综合、实现，但需要正确项目结构、接口、约束和调用顺序。
Agent仍需完成什么
定位跨文件问题、管理状态、完成正确集成和可独立验证的最终交付。
研究用途判断
适合做工程agent主线，优先有冻结任务/独立验收和完整运行记录的分轨。
必须保留的验收
按原任务全条件通过；检查点部分分、可运行和完整功能/物理成功分列。
数据可得性
EDA-env有最终patch；ASIC-Agent20题官方入口404；不能把最终补丁叫完整轨迹。
饱和/版本/可比性边界
不同套件的隐藏oracle/商业工具/模型预算不一致，不把部分分88%与整题Pass混榜。

对应目录：CVDP / agentic project workflow · EDA-env / 57 completion and engineering-repair tasks · ASIC-Agent-Bench / open-ended ASIC engineering milestones

数字验证

性质、测试和覆盖闭环

成熟工具已经承担什么
形式求解器证明给定性质，仿真器执行给定激励，coverage工具计算给定覆盖模型。
Agent仍需完成什么
从规格写对性质与测试、识别覆盖缺口、避免空泛证明并决定下一步激励。
研究用途判断
适合继续研究，但要先保证覆盖模型与规格语义独立。
必须保留的验收
有效性/非空性/规格覆盖、mutation检出与资源预算；proven比例和性质数量不能独立作成功。
数据可得性
有论文/局部记录，完整cross-model动作与反馈通常未齐。
饱和/版本/可比性边界
Saarthi出现性质数或coverage提升但proven比例下降的组合；HORIZON coverage分母含parsed日志边界。

对应目录：Saarthi 2026 / six-design KPI, HIL and coverage protocols · FIXME / SVAGen：断言生成与形式验证 · NVIDIA HORIZON / repository-evolution method evaluation

模拟前端

长程晶体管级电学设计

成熟工具已经承担什么
SPICE负责给定netlist的电路求解，数值optimizer可搜索给定参数空间。
Agent仍需完成什么
理解规格、选拓扑/器件、构造合法电路、安排实验、在预算内闭合全部电学要求。
研究用途判断
适合做模拟agent主评测，需保持独立verifier与工艺边界。
必须保留的验收
合法性+全部电学spec；nominal/PVT/MC/PEX层次各报，全部attempt和超时计分。
数据可得性
50任务/独立verifier协议已有作者发布；完整provider轨迹可得性单独核。
饱和/版本/可比性边界
SPICE已成熟只表示forwardoracle成熟，不代表模型已经能自动完成所有模拟设计。

对应目录：Analog Design Bench (Long-Horizon)

模拟前端

固定拓扑尺寸与优化器编排

成熟工具已经承担什么
BO/GA/局部搜索和SPICE已能做大量固定拓扑数值优化；部分方法内部本就调用这些工具。
Agent仍需完成什么
确定变量/范围/预算、解释失败、选择优化策略和必要时更换拓扑。
研究用途判断
适合衡量样本效率与meta-optimization；避免把原生BO收益全计作LLM贡献。
必须保留的验收
相同拓扑/范围/全simulationbudget的强原生基线；全部实际spec硬门、单位/符号一致。
数据可得性
AutoSizer任务可读；AnalogSAGE只有52×15迭代成败摘要，不是全量数值反馈轨迹。
饱和/版本/可比性边界
AnalogSAGE52中27复用源任务；论文10×5与current52×15不同，100%任务覆盖不等100%trial通过。

对应目录：AMS-SizingBench / 24 SKY130 circuit sizing tasks · AutoSizer / reflective sizing meta-optimization agent · AnalogSAGE current / 52 mixed-source circuit tasks and summary logs

成熟工具已经承担什么

饱和/版本/可比性边界

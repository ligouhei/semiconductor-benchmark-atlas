# Semiconductor Benchmark Atlas / 芯片行业 Benchmark 分类表

在线浏览：https://ligouhei.github.io/semiconductor-benchmark-atlas/

674 条任务/版本记录，376 个家族/对象，14 个领域。涵盖模拟与数字前端、验证与综合、布局布线、时序功耗、OPC/光刻、测试及封装等。

打开 `index.html` 可搜索、筛选、分页、查看输入/任务/指标/版本/基线/许可/限制/一手来源，并导出筛选结果 CSV；无需安装依赖，可离线打开。

资料截至 2026-10-20。本项目为公开资料、源码和数据的静态研究汇总，未实际运行 EDA 或模型。条目数不等于独立成熟公开数据集数。商业工具具有某项功能不自动证明任务已解决；研究判断与来源事实、已发布协议与拟议协议分别注明。

网页使用公开发布文件白名单。原始下载、第三方数据包、隔离原件、凭据与工作日志不包含在本仓库中；完整报告中的部分缓存链接已改为一手来源或标明为本地附件。原始基准、论文、数据、工具和 PDK 的许可及权利属于各自权利人，公开说明不授予它们的再分发或商业使用授权。
